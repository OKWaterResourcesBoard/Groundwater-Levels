# OWRB GMAP Groundwater Level Well Index

Interactive groundwater level hydrographs and data tables for wells monitored under the Oklahoma Water Resources Board (OWRB) Groundwater Monitoring and Assessment Program (GMAP).

---

## Overview

This site provides public access to groundwater level data collected by the OWRB GMAP program. Each well has a dedicated page displaying:

- A hydrograph of depth to water over time
- A searchable data table of all measurements
- Well metadata including name, aquifer, and county

Data is sourced from the OWRB AWQMS (Ambient Water Quality Monitoring System) database via the public API.

---

## Site Structure

```
index.html               # Master well index -- search and sort all wells
Branded-Logo-OWRB.svg    # OWRB branding
wells/
  <well_id>.html         # Individual well page (one per well)
```

---

## Features

**Index Page**
- Search across Well ID, Well Name, Aquifer, and County simultaneously
- Sort any column ascending or descending
- Live row count updates as you search

**Well Pages**
- Hydrograph with inverted y-axis (deeper = down)
- Click any data point on the graph to highlight and scroll to that row in the table
- Time period slider -- filter the chart to Period of Record, Last 20, 15, 10, or 5 years
- Reset button to return to full period of record
- Save Graph button -- downloads a PNG of the chart with well metadata included
- Clear Selection button to remove table row highlighting
- Links sidebar with quick access to OWRB and DPC resources

---

## Data

- **Organization:** OWRB-GMAP
- **Parameter:** Depth, from ground surface to well water level
- **Projects included:** GMAP Water Level Data, OLD GMAP Baseline WL
- **Units:** Feet (ft)
- **Source:** [OWRB AWQMS API](https://owrb.gselements.com/api/)

## Updating the Data

The site is generated by `GMAP_HTML_Generator.R`. To refresh with the latest data:

1. Open `GMAP_HTML_Generator.R` in RStudio
2. Run the full script -- it will re-pull all data from the API and regenerate all HTML files
3. Push the updated files to GitHub:

```bash
cd "path/to/Groundwater"
git add .
git commit -m "Data refresh - YYYY-MM-DD"
git push
```

GitHub Pages will update within a minute or two.
